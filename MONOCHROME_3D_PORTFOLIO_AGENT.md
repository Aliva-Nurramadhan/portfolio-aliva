# Motion Philosophy

Animation exists to communicate.

Use:

- Framer Motion
- Lenis
- GSAP (only where necessary)

Motion includes:

- Fade

- Translate
- Parallax
- Stagger

- Magnetic buttons
- Smooth page transitions
